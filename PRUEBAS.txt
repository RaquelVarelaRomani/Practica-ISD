// Datos de las "encuestas populares":
//   Id 1: Porcentaje afirmativas: 50,00%, Dias hasta finalizacion: <dias hasta 2026-08-01>, Cancelada: No
//   Id 3: Porcentaje afirmativas: 0,00%,  Dias hasta finalizacion: <dias hasta 2026-12-01>, Cancelada: No

//Devuelve encuesta con id 1 (2 respuestas)
